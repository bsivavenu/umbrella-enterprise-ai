👥 Human-in-the-loopAdministrators approve or reject sensitive requests

Sensitive request detected
keywords: delete, export, send to, update policy
→
Approval request created
approvals row, status pending; user told to wait
→
Admin review
Approvals tab: approve ✔ or reject ✘
→
Decision recorded
status + reviewer + audit event; nothing is executed
Tenant isolation: every SQL query filters on tenant_id; Pinecone namespace tenant-<name>. Access control: a chunk is searchable only by members of its allowed groups or its owner. Settings: all in .env, read by app/config.py.
