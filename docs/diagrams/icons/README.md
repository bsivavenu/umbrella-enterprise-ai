# Icons used in the diagrams

- `anthropic.svg`, `fastapi.svg`, `html5.svg`, `javascript.svg`, `langchain.svg`, `postgresql.svg`,
  `python.svg`, `render.svg`: from [Simple Icons](https://simpleicons.org) (the icon files are CC0).
  The logos themselves are trademarks of their owners and are used here only to name the services.
- `bucket.svg`, `vectors.svg`, `chip.svg`: simple symbols drawn for this project to stand in for
  Amazon S3, Pinecone and OpenAI. Their official logos were not available from the icon library,
  so they are not reproduced.

The editable diagrams are `../architecture.html` and `../workflow.html` (open them in a browser). The styled PNGs shown in the README, in `docs/`, were made separately from the same content.
