Umbrella AI – Workflow

How a document gets in, how a question gets answered, and how sensitive requests are approved

A 📤 Upload and ingest a document Documents tab → searchable in a few seconds

1BrowserChoose a fileSends the filename to the uploads endpoint. Only .pdf .docx .txt .md are accepted.
2FastAPIRegister itCreates a documents row (pending) + audit event. Returns a temporary S3 upload link (5 min).
3S3Upload the fileBrowser sends the file straight to S3 with the presigned PUT. The server never handles the bytes.
4BrowserSay it is doneCalls the complete endpoint with the document id. A document of another tenant gives 404.
5WorkerLock and downloadRow locked, status processing. Checks: ≤ 10 MB, real PDF header.
6WorkerParse and chunkPDF by page, DOCX, text. Cut into 1200-character chunks overlapping by 180.
7OpenAI + PineconeEmbed and storeEach chunk → 1024 numbers. Upsert with text, title, page, owner, groups (batches of 50).
8PostgresMark readyStatus ready + audit event. On any error: failed, can be retried.

B 💬 Ask a question Knowledge chat → cited answer

1UserAskPOST /api/chat with the question and conversation id.
2🛡️ Input guardrailSafe?Not empty, no injection or secret-request patterns.
3🛡️ HITL checkSensitive?Contains delete, export, send to, update policy?
4PostgresLoad historyLast 6 question/answer pairs of this conversation.
5RetrieveSearchEmbed the question (+ previous one). Pinecone query with the access filter, then drop scores < 0.30.
6RouteEvidence found?Passages left after the cut-off?
7AnthropicGenerateAnswer from numbered passages and history, citing [1], [2].
8🛡️ Output guardrailClean?No leaked keys or passwords in the answer.
9PostgresSave and replySave the turn. UI shows markdown answer, sources, 👍, Copy.
BlockedHTTP 400 + audit event (input blocked). Nothing is searched.
HeldApproval row (pending), reply “needs administrator approval” → lane C.
No evidenceFixed reply “could not find supporting evidence…”. The model is not called.
Leak foundAnswer replaced, audit event (output blocked), sources hidden.
Access control happens inside step 5: Pinecone only returns chunks whose allowed groups include one of the user's groups, or that the user owns, inside the user's tenant namespace. Text the user may not read never reaches the model.

C ✅ Human-in-the-loop approval Approvals tab (administrators)

1🛡️ DetectedSensitive request heldFrom lane B step 3. The question is stored, not answered.
2PostgresApproval createdapprovals row, status pending, requester recorded, audit event.
3👤 AdminReviewApprovals tab lists requests (admins only; others get 403). Click Approve or Reject and confirm.
4FastAPIDecision savedThe decision endpoint updates status, reviewer and time. Only pending requests can be decided.
5📋 Audit logRecorded onlyAudit event written. The response says executed: false; no delete or export is performed.
